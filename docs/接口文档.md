# 接口文档

API统一前缀`/api`；在线OpenAPI为`/docs`。成功响应`{code:0,message:"ok",data:...}`；失败响应带HTTP状态与`{code,message,data:null}`。JSON字段使用Pydantic校验；文件导出直接返回相应文本，不包装统一JSON。

| 方法 / 路径 | 用途 |
|---|---|
| GET /health | 服务模式、数据库类型、云服务是否已配置（不返回Key） |
| GET /documents；GET /documents/{id}；POST /documents | 来源列表、原文查看、导入不可覆盖原文版本 |
| GET/POST /datasets；PUT/DELETE /datasets/{id} | 题集管理 |
| GET/POST /datasets/{id}/questions | 题目列表/新增，GET支持type/status筛选 |
| PUT/DELETE /questions/{row_id} | 题目编辑/删除 |
| POST /datasets/{id}/import | JSON/CSV批量导入，整批事务校验 |
| GET /datasets/{id}/quality；GET /datasets/{id}/export | 质量统计/泄漏检查、题集导出 |
| GET/POST /configs；POST /configs/{id}/clone | 配置版本管理；克隆可编辑完整参数 |
| GET /configs/{id}/export?format=yaml或json | 配置导出 |
| GET/POST /runs；GET /runs/{id} | 创建任务、查询进度与固定抽样 |
| POST /runs/{id}/pause；POST /runs/{id}/resume | 暂停与续跑 |
| GET /runs/{id}/metrics | 指标、样本分母、成功覆盖率、调用统计 |
| GET /runs/{id}/items | 逐题分页；config_id/type/bad_only/sampled_only/tag筛选 |
| GET /items/{id} | 题目、生成、召回、评分、耗时、错误、尝试次数 |
| PUT /items/{id}/tags；PUT /items/{id}/human-review | 人工归因、独立评分 |
| GET /runs/{id}/bad-cases | 标签与高频失败问题 |
| GET /runs/{id}/calls | 所有真实API尝试、用量和阶段状态 |
| GET /compare?left=历史ID&right=当前ID | 固定版本校验与配置指标差值 |
| GET /runs/{id}/export?format=csv或markdown或human | 指标/报告/人工记录导出 |

## 请求示例

创建演示任务：

```json
{"name":"六配置100题工程验证","dataset_id":"dataset-demo","config_ids":["config-c01","config-c02","config-c03","config-c04","config-c06","config-c07"],"mode":"demo","concurrency":3,"sample_seed":42}
```

响应包含实际运行生成的ID：`{"code":0,"message":"ok","data":{"id":"run-..."}}`。不得将示例占位符当作真实ID。`docs/接口真实示例.json`由本机实际接口请求生成，包含真实响应与运行ID。

正式任务将mode设cloud，dataset_id改为人工审核完成的题集ID；未审核会返回400，且不会创建任何模型调用。暂停中尚有在途项时resume会返回400，等待状态paused再续跑。

人工评分请求：

```json
{"accuracy":4,"completeness":4,"refused":false,"unsupported":false,"factually_incorrect":null,"reviewer":"真实评分人","note":"在此记录证据与判断"}
```

该请求仅作为格式示例，不代表已有人工评分。服务保存实际UTC时间，界面按浏览器时区显示。详细指标分母及一致率见评测指标口径。
