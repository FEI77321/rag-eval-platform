# 评测指标口径

固定版本：准确性≥4且完整性≥4视为答案要点通过；回答题还要求没有错误拒答，拒答题要求确实拒答。Judge分数范围1—5。生成与Judge分别保存。

## 检索指标

标准证据为题目`evidence`中多个去重的人工标注来源，每个来源含文档ID、原文quote和起止坐标。每个召回块有相同坐标体系。

命中规则：同一文档中，某召回块与标准证据的交叠字符数 / 标准证据字符数 ≥ 配置`evidence_coverage`（默认0.8），算覆盖该证据。每条证据只计一次；多个重叠块不能重复加分。当前按单块覆盖判断，跨多个碎片合并覆盖不计命中，便于暴露证据被切碎的问题。

| 指标 | 单题定义 | 汇总分母 / 边界 |
|---|---|---|
| 证据Recall@K | 前K个最终上下文覆盖的标准证据项数 / 标准证据项总数 | 对成功回答题作宏平均；拒答题N/A排除；无命中为0 |
| 来源Hit@K | 至少覆盖一条标准证据为1，否则0 | 成功回答题数；兼容原需求的“标准块是否出现”口径 |
| 全证据命中率 | 全部必要证据均被覆盖为1，否则0 | 成功回答题数；多跳题重点观察 |
| MRR@K | 第一个相关结果排名r的1/r，前K无命中为0 | 成功回答题数；相关判定采用同一证据覆盖规则 |
| Hit@1 | 第一条结果覆盖任一标准证据为1，否则0 | 成功回答题数 |

评测对象为Rerank后截取Top-K、实际传给生成的块；候选召回池另行保存用于诊断。语义分块真实模式由云Embedding控制句间边界，demo模式使用Hash向量作流程模拟。

`gold_chunk_id`保存固定500字符/重叠80基线的实际块ID；跨策略对比以标准证据坐标为准。由于任意分块不能直接比较块ID，前端主图显示证据Recall，同时保留Hit指标和全证据指标。标准块被切断但多个块拼接可回答时，检索指标和答案质量可能不同，报告需解释。

## 生成指标

- 回答正确率：成功回答题中准确性≥4、完整性≥4且未拒答的比例。分母不含拒答题。
- 拒答正确率：成功拒答题中准确性≥4、完整性≥4且Judge判为拒答的比例。没有拒答题时N/A。
- 全题任务成功率：上述两类成功判定合并 / 全部成功完成题目。便于按题型权重比较配置，同时附各题型成功率。
- 无依据主张率：Judge判断存在知识库依据之外的实质主张 / 所有成功完成题目。单独展示，不等同幻觉率。
- 幻觉率：同时“无依据实质主张”且“能确认事实错误”的题目比例。`factually_incorrect=null`且存在无依据主张时为待复核，排除幻觉率分母；不含无依据主张时幻觉标记为0。必须同时报告`hallucination_n`，未知不能当作正确或0。

正式模式使用LLM评分，demo规则仅为回归演示。标准答案不会传入生成函数，只进入独立Judge。规则判定不能替代人工核验。

## 失败与覆盖率

质量均值只使用`state=succeeded`且有完整metrics的结果。失败项不能悄悄丢弃：同表列出`total/succeeded/failed/success_coverage`及每项指标有效样本数`*_n`。不同成功覆盖率时不能直接宣称更优。验收600次问答要求600个成功项。

## 延迟和用量

- 检索时间含问题Embedding、向量/BM25/RRF阶段及该阶段退避。
- Rerank单独计时；生成单独计时；问答`qa_ms`包含上述串行阶段。
- Judge计时单独保存。问答延迟不含Judge、任务排队和建索引；整个跑批含这些开销，应依据任务时间另行报告。
- 平均延迟取所有成功项的算术平均；P95采用NumPy percentile默认线性插值。失败项耗时在调用账本披露，不混入成功问答平均。
- 生成与Judge分别保存API真实输入/输出Token；模拟模式为null，不能填造真实Token。
- 单次对话评测成本 = 生成输入/输出Token×相应每百万价格 + Judge输入/输出Token×相应价格。平均为成功项平均；任何用量或价格未知时为N/A。
- 默认价格只适用于默认生成模型；配置换模型且未设置单独价格时N/A。Embedding、Rerank、重试计费、缓存价格差异和阶梯价未纳入该估算，需结合ApiCall用量和厂商账单独立结算。

## 人工评分与一致率

用固定种子从题目ID分层随机抽取ceil(20%题数)，容量允许时保证每类至少一题。保存抽样ID；对这批题目在每套配置下的答案评分。例如100题×六配置，抽20题并评120条答案。

- 分数完全一致率：准确性与完整性两个分数同时相等的配对答案数 / 有人工评分与Judge结果的配对答案数。
- 二分类一致率：人工/Judge分别按相同阈值和题型拒答规则转成通过/不通过后，相等的比例。
- 当前聚合包含所有已人工评分的成功项；导出标明是否属于固定抽样。正式报告应确保抽样全部完成，并区分额外评分的结果。
- 没有配对人工评分时N/A。分数差一以内不作为主一致率。先独立评分再查看Judge，以减少锚定。

## 对照与统计边界

同一题集、语料、Prompt、Judge及Embedding服务版本方可进行直接历史对照。Top-K折线只取其余参数一致的配置；Rerank开关与相同混合基线配对。开发评测集调参后选优的结果不能代表独立测试集泛化效果。样本量有限时避免仅凭小幅差异宣称稳定增益。
