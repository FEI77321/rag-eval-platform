- FastAPI、Pydantic、SQLAlchemy后端；Vue3/Vite/ECharts前端。
- 评测集与题目增删改查、题型筛选、JSON/CSV批量导入、导出、质量统计、题目原文字符串泄漏检查。
- 固定/递归/语义分块；向量/BM25+RRF混合检索；重排开关、候选数、Top-K、阈值、模型、思考模式和单价配置；九套持久版本及YAML。
- 配置克隆/修改创建独立新版本，参数并排差异对照。
- Recall/Hit/MRR/Hit@1、答案正确率、拒答率、幻觉率、无依据主张率、平均/P95延迟、真实Token与对话成本估算能力；有效样本分母与未知处理。
- 独立Worker、异步并发、RPM限制、429/暂时故障退避、心跳租约、逐题逐配置恢复、生成与Judge分阶段保存。
- 原始召回、答案、结构化评分、阶段耗时、API尝试用量账本持久化；从数据库重新分析和导出，无需重跑模型。
- 六类Bad Case标签、自动建议与人工修订、备注、标签统计及失败频次；固定种子20%抽样、独立人工评分和一致率计算。
- 六个工作页面、质量对比柱状图、受控Top-K折线、成本/延迟散点（真实成本齐备才显示）、逐题下钻、任务轮询与暂停续跑。
- 本地模拟六配置100题完成600/600；后续九配置100题完成900/900。
- 实际运行暂停后续跑：暂停时3条已成功，恢复后900/900完成；检查这3条attempts仍为1且generation完全相同。历史九配置对比版本一致。
- 19项后端测试通过，包括指标边界、来源/审核验证、任务恢复、Judge失败不重生成、失联接管、云请求/Embedding批次/调用账本协议。云协议测试使用受控fixture，不是实网云模型测试。
- 浏览器逐页、弹窗、下钻验证通过；390px页面未横向溢出；无JavaScript异常。
- 12份真实官方教程 / 334个固定500/80基线块，原文URL、版本哈希、授权说明与快照保存。
